Chain Walker
engine/chain.rs · pub fn bind_member_access()
Resolves member-access chains (a.b.c()). Entity-based walk: holds a TypeId at each hop — never re-parses type strings mid-chain. Analogous to Roslyn's DataFlowAnalysis + symbol-info binding on member access expressions. The walk threads a Receiver (TypeId + optional symbol id) hop-by-hop.
Walk steps:
1. resolve_root: local_type cache → declared annotation → callee_return_type → value_root_type
2. expand_receiver: alias::expand (AliasTarget) → head_symbol_id
3. lookup_member_on: by id (members_by_id) → by qname (members_by_parent) → mapped-type source
4. yield_through: return_type_id / field_type_id → substitute generic params → TypeId for next hop
