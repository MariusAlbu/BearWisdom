INFER-1 — Control-flow-graph narrowing · §B item 1 · foundational · ▷ STARTING

Narrowing today is lexical-block + early-return only — there is no control-flow graph. INFER-1 adds a per-function CFG the narrowing pass walks: facts ride the edges, merge at join points, reset on reassignment, reach a fixed point over loop back-edges, split across &&/||, and bottom out at never for exhaustive switches. The foundational checker feature — it caps how far INFER-2..4 reach. Rose-dashed = today's gap.

CURRENT · block-scoped + early-return narrowing; no graph to see merges, loops, or kills

The flow pass (type_checker/, indexer/flow) narrows within a lexical block and after an early return — enough for the two simple shapes. With no CFG it cannot model: a reassignment that should kill a narrowed fact, an if/else join that unions the branches, a loop back-edge, a short-circuit &&/|| guard, or switch exhaustiveness. Those five are silently wrong or absent.

TARGET · a per-function CFG; narrowing facts flow on edges and merge at joins

build_cfg(fn) produces basic blocks and edges. The narrowing pass walks it: each edge carries the fact implied by the branch condition; join blocks merge predecessor facts (then ∪ else); a def block resets the fact; loop back-edges iterate to a fixed point; &&/|| lower to extra edges so the guard fact sits on the true edge; an exhaustive switch leaves the default block unreachable (never). The same five cases now fall out of graph structure.
