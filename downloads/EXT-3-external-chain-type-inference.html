EXT-3 — Lazy member hydration, origin-blind · §C item 3 · D3/S4 · ✓ LANDED (fa0a1e43)

Chains through an external type. Member lookup already works origin-blind; what's missing is carrying generics through external return types and walking supertypes over external bases. Example: class UserRepo extends Repository<User> (Repository external), then repo.find().email. Rose-dashed = divergence from the compiler model.

CURRENT · members resolve; generic args drop and external supertypes stop at one hop

Member lookup is origin-blind (qualified_member_lookup, chain.rs:638) so repo.find() finds find on the pulled Repository. But the external edge's <User> isn't bound, so find() yields the unbound param T and the next hop dies. And build_explicit skips ext: files (supertype.rs:217), so Repository's own supertypes aren't in the graph — an inherited method one level deeper misses.

TARGET · generics composed across external edges, supertypes climbed (bounded)

Bind the external method's type params to the edge's concrete args (Repository.T → User) via bind_apply_args + substitute, so find() yields User and the chain walks. Include reachable external bases in the supertype walk so the climb continues through the external hierarchy with composed args — bounded to externals the chain actually reaches (pulled on demand by EXT-1/EXT-2), never the whole dep tree.
