QUAL-5 — Three-state external model · §E item 5 · pairs with EXT-1 · ▷ STARTING

Resolution today is binary: a ref is a RESOLVED edge or it is UNRESOLVED. An import-qualified external whose package metadata isn't on disk looks identical to a typo. QUAL-5 splits the miss bucket into external_known_unhydrated (scope names a real dep, its source is absent) vs unresolved_unknown (the genuine gap) — so precision is measurable, not hidden in one coverage rate. Orange = known-but-unhydrated.

CURRENT · two states — a missing dep source and a typo land in the same bucket

The binder either binds a declaration (RESOLVED) or it doesn't (UNRESOLVED). The "didn't" bucket merges a ref whose import names a real dependency whose metadata was never pulled, with a ref that binds to nothing because it is genuinely wrong. The coverage rate is one number over that merged denominator — so precision is unobservable: you can't tell a dep-source gap from an actual resolution failure.

TARGET · three states — dep-source gaps separated from genuine unknowns

A miss is classified once more: does scope/import name a known dependency? If yes but its source isn't hydrated, the outcome is external_known_unhydrated — a bounded, named gap (the same signal EXT-1's locate miss-under-module produces). If no dependency owns the name and nothing binds, it is unresolved_unknown — the real defect. The metric reports three buckets: precision = resolved / (resolved + unknown), with unhydrated tracked apart as a dependency-availability gap, not counted against the engine.
